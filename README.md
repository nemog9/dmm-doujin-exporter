# DMM Doujin Exporter

DMMマイライブラリの同人作品（ボイス・コミック・CG）を、[Hikidashi（引き出し）](https://nemog9.github.io/hikidashi-support/)形式のCSVにエクスポートするChrome拡張機能。

エクスポートしたCSVは、iOSアプリ Hikidashi の「CSVをインポート」で取り込めます。

> 非公式のツールです。DMM／FANZAとは関係がありません。自分の購入履歴を、自分のブラウザで取得して、手元のCSVに保存するためのものです。

📱 iPhone アプリ: [Hikidashi（引き出し）を App Store で入手](https://apps.apple.com/jp/app/hikidashi-%E5%BC%95%E3%81%8D%E5%87%BA%E3%81%97/id6823911890)
🧩 ページを 1 つずつ保存するなら: Chrome 拡張 [Hikidashi クリップ](https://github.com/nemog9/hikidashi-clip)（QR で iPhone に保存）

## 機能

- マイライブラリをスクロールして作品情報を自動収集
- 声優（ボイス作品）・作者（コミック・CG作品）を各作品の詳細ページから取得
- 既存CSVとのマージ出力（前回の続きから差分のみ取得）
- 既定は最後までスクロールして全件を確認。「高速モード」にすると、既存の作品に当たった時点で止まる

## 出力形式

Hikidashi（iOS アプリ）にそのまま取り込める CSV。UTF-8 BOM 付き。

```
"title","url","creators","thumbnail_url","category","note","favorite","hidden"
```

| 列 | 内容 |
|----|------|
| title | 作品名 |
| url | 作品詳細ページの URL（`https://www.dmm.co.jp/dc/doujin/-/detail/=/cid=<作品ID>/`）。購入済みページ（マイライブラリ）の URL ではない |
| creators | サークル名・声優（ボイス）・作者（コミック・CG）を `|` 区切りでまとめたもの |
| thumbnail_url | サムネイル画像 URL |
| category | ジャンル（ボイス / コミック / CG / 動画） |
| note | メモ（新規取得分は空。既存 CSV の値は保持） |
| favorite / hidden | `1` / `0`（新規取得分は空 = 取り込み先の既存値を保持） |

### 既存 CSV の読み込み（差分取得）
購入済みページの URL（`.../mylibrary/detail/=/product_id=…`）が入った CSV は、作品詳細 URL に変換して出力する。作品 ID はどちらの URL からも取り出すので、差分取得は URL の種類に関係なく動く。

CSVShelf 形式に加え、旧形式（`タイトル,サークル名,声優,ジャンル,URL,サムネイル,お気に入り,非表示`）も読める。
旧形式を読み込んだ場合は、新形式に変換して出力する（サークルと声優は creators にまとめる）。
CSVShelf から書き出した CSV を読み込めば、お気に入り・非表示・メモを保ったまま差分だけ追加できる。

## インストール

Chrome ウェブストアでは配布していません。次の手順で、手元の Chrome に読み込みます（Edge など Chromium 系でも同様です）。

1. [Releases](https://github.com/nemog9/dmm-doujin-exporter/releases/latest) から `dmm-doujin-exporter-vX.Y.Z.zip` をダウンロードして、解凍する（解凍したフォルダは、使い続ける間、削除しない）
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」から、解凍したフォルダを選択
5. 更新するときは、新しい zip で同じフォルダを上書きし、`chrome://extensions` の拡張機能のカードで「再読み込み」を押す

ソースから使う場合は、このリポジトリをクローンして、同じ手順でフォルダを選べます。

## iPhone（Safari）で使う：Userscripts 版（試験的）
PC がなくても、iPhone の Safari で、マイライブラリを CSV にできます。無料のアプリ [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) を使います。

1. App Store で「Userscripts」を入れ、アプリを開いて、スクリプトの保存フォルダを選ぶ。
2. 「設定 → アプリ → Safari → 機能拡張 → Userscripts」をオンにして、`dmm.co.jp` へのアクセスを許可する。
3. [`userscript/dmm-export.user.js`](userscript/dmm-export.user.js) を、手順 1 のフォルダに入れる（Raw を Safari で開いて、`aA` →「Userscripts」からインストールしてもよい）。
4. Safari で DMM にログインし、マイライブラリを開く。画面の下に「Hikidashi 書き出し」のパネルが出る。
5. 初回は「全件を取得」、2 回目以降は「新着だけ」を押す。**終わるまで、Safari を前面に出したまま、画面を開いておく**（画面が消えないようにする設定を使っていますが、ほかのアプリに切り替えると止まります）。進み具合と残り時間が出ます。
6. 完了したら「CSV を保存」を押す（ダウンロードの確認が出たら許可）。保存した CSV を、Hikidashi の「設定 → CSV をインポート」で選ぶ。

- 仕組みは Chrome 拡張と同じです（購入履歴を、自分の Safari の中だけで処理して、外部には送りません）。
- `userscript/probe.user.js` は、画面の構造を調べるための診断用です（通常は使いません）。

## プライバシー

- 取得した内容は、**ブラウザの中だけ**で処理して、CSVとして手元に保存します。作者を含め、外部のサーバーには、何も送信しません。
- 通信するのは、ログイン済みのあなた自身の DMM のページ（`www.dmm.co.jp`）だけです。
- 権限（`activeTab`、`scripting`、`tabs`、`downloads`、`storage`）は、マイライブラリのページの読み取りと、CSVの保存、設定の保持にだけ使います。

## 使い方

1. DMMにログインし、[マイライブラリ](https://www.dmm.co.jp/dc/-/mylibrary/)を開く
2. 拡張機能アイコンをクリック
3. （任意）前回エクスポートしたCSVを読み込む → 差分のみ取得してマージ出力される
4. 「取得件数」を設定（0で全件）
5. 「取得開始」をクリック

### 最後までスクロール（既定）／高速モード

既定では、ライブラリを**最後までスクロール**して全件を確認し、CSV にない作品だけを取得する。  
「最後までスクロール」のチェックを外すと高速モードになり、既存の作品に当たった時点で止まる（前回の続きだけを取りたいときに速い。ただし、途中に未取得の作品があると取りこぼす）。

### ファイル名

前回のCSVを読み込んだ場合、そのファイル名のベース部分（例: `my-library`）に現在の日時を付けて保存される。

```
my-library-20260501-153000.csv
```

CSVなしで開始した場合は `doujin-library-YYYYMMDD-HHMMSS.csv` で保存される。

## 動作の流れ

```
① スクロールフェーズ
   マイライブラリページを自動スクロールして作品一覧を収集
   （既定は最後までスクロール。高速モードでは、既存IDと重複した時点で停止）

② 声優・作者取得フェーズ
   新規作品のみ詳細ページをfetchして声優/作者を取得

③ CSV出力
   既存CSVの内容 + 新規作品をマージしてダウンロード
```

## 開発

```
node --test test/csv.test.mjs
```

CSVの読み書きは `csv.js`（popup と Service Worker で共有）。

## 途中で止まるとき
完了メッセージに「ライブラリ N 件を確認。停止理由: …」が出る。
- **既存の作品に到達した（重複検知）**: 既存 CSV を読み込んでいると、すでにある作品に当たった時点で止まる。ライブラリの途中に未取得の作品があるなら「全件探索モード」を使う。
- **最後まで読み込んだ**: 新しい作品が最大 20 秒待っても増えなくなったら終了とみなす（約 1 分程度の遅い読み込みでも途中で諦めない）。確認件数がライブラリの実際の件数より少なければ、DMM 側の読み込みが止まっている可能性がある。
- **取得件数の上限に達した**: 「取得件数」に 0 以外を入れている。

## 注意事項

- DMMのマイライブラリページを開いた状態で使用してください
- 作品数が多い場合、取得に時間がかかります（1作品あたり約0.5秒）
- DMMのページ構造変更により動作しなくなる場合があります（不具合は Issues へ）
- 短時間に大量のアクセスをしないよう、1作品ごとに待ち時間を入れています。DMMの利用規約に従って、自己責任でお使いください
