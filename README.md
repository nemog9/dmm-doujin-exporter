# DMM Doujin Exporter

DMM（FANZA）のマイライブラリにある購入済みの同人作品（ボイス・コミック・CG）を、[Hikidashi（引き出し）](https://nemog9.github.io/hikidashi-support/)に取り込める CSV にする、**iPhone（Safari）と PC（Chrome）用のツール**です。

> 非公式のツールです。DMM／FANZA とは関係がありません。自分の購入履歴を、自分のブラウザの中だけで処理して、手元の CSV に保存するためのものです。外部のサーバーには、何も送りません。

| 使う端末 | 方法 | 準備 |
|---|---|---|
| 📱 **iPhone** | Safari + 無料アプリ「Userscripts」 → [手順](#-iphoneで使うsafari--userscripts) | アプリを 1 つ入れて、設定を 3 つ変える |
| 💻 **PC** | Chrome 拡張機能 → [手順](#-pcで使うchrome拡張機能) | zip を展開して、拡張機能に読み込む |

出来上がった CSV は、iPhone アプリ [Hikidashi（引き出し）](https://apps.apple.com/jp/app/hikidashi-%E5%BC%95%E3%81%8D%E5%87%BA%E3%81%97/id6823911890) の「設定 → CSV をインポート」で取り込みます。
ページを 1 つずつ保存するなら、Chrome 拡張 [Hikidashi クリップ](https://github.com/nemog9/hikidashi-clip)（QR で iPhone に保存）もあります。

## 📱 iPhoneで使う（Safari + Userscripts）

PC がなくても、iPhone だけで、マイライブラリを CSV にできます。「Userscripts」は、Safari の中で、決めたサイトにだけ、小さなプログラム（スクリプト）を動かせる、無料のアプリ（拡張機能）です。

> 設定の画面の名前は、iOS のバージョンで、少し違うことがあります。**手順 2 の設定を、すべて済ませないと、動きません。** つまずきやすいので、順番どおりに進めてください。

### 手順 1　Userscripts アプリを入れて、保存フォルダを選ぶ
1. App Store で「[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)」（作者: Justin Wasack、無料）を入れる。
2. **Userscripts アプリを、一度、開く。**
3. 「スクリプトの保存先フォルダ」を選ぶ（画面の案内に従う）。「ファイル」アプリの「このiPhone内」に、新しいフォルダ（例：`Userscripts`）を作って選ぶのが簡単です。
   - このフォルダに、スクリプトのファイル（`.user.js`）が保存されます。

### 手順 2　Safari で、Userscripts を使えるようにする（ここが一番つまずきます）
1. iPhone の「**設定**」アプリを開く。
2. 「**アプリ**」→「**Safari**」→「**機能拡張**」を開く。
3. 「**Userscripts**」を選び、「**拡張機能を許可**」を**オン**にする。
4. 同じ画面で、「**他の Web サイト**」を「**許可**」にする。
   - ここが「**確認**」や「**拒否**」のままだと、スクリプトが、DMM のページで、動きません。
   - 「すべての Web サイト」を許可したくない場合は、下の「Web サイトへのアクセス」の一覧で、**`dmm.co.jp`（または `www.dmm.co.jp`）だけ**を「許可」にします。
5. 「プライベートブラウズ」を使っている場合は、**通常のタブ**で開くようにする（プライベートでは、拡張機能が動かないことがあります）。

### 手順 3　スクリプトを入れる
次の **A（URL から）** か **B（ファイルで）** のどちらかです。

**A．URL から（簡単）**
1. Safari で、次の URL を開く（ブラウザに、スクリプトの文字が、そのまま出ます）。
   `https://raw.githubusercontent.com/nemog9/dmm-doujin-exporter/main/userscript/dmm-export.user.js`
2. アドレスバーの左にある「**ページメニュー**」のアイコンをタップ →「**Userscripts**」を開く。
   - アイコンは、iOS 26 までは「**ぁあ**」（英語表示では「aA」）、**iOS 27 では、横線が 2 本、縦に並んだ（リーダーのような）アイコン**です。
3. 「**Install**」（インストール）のボタンが出たら、タップする。確認が出たら、許可する。
   - 出ない場合は、B の方法にしてください。

**B．ファイルで**
1. [Releases](https://github.com/nemog9/dmm-doujin-exporter/releases/latest) から、`dmm-export.user.js` をダウンロードする（Safari で開いて、長押し →「ダウンロードしたファイルをリンク」でもかまいません）。
2. 「ファイル」アプリで、ダウンロードしたファイルを、**手順 1 で選んだ保存フォルダに、移動**する。
3. Userscripts アプリを開き、一覧に出ていることを確認する。

### 手順 4　マイライブラリを開く
1. Safari で DMM にログインし、[マイライブラリ（https://www.dmm.co.jp/dc/-/mylibrary/）](https://www.dmm.co.jp/dc/-/mylibrary/) を開く。
2. 画面の下に、オレンジ色の枠の「**Hikidashi 書き出し**」のパネルが出れば、準備完了です。
   - **作品の詳細ページでは、パネルは出ません**（一覧のページだけです）。
   - 出ないときは、ページを再読み込みして、下の「うまくいかないとき」を見てください。
   - 「デスクトップ用 Web サイトを表示」にする必要は、ありません。

### 手順 5　書き出す
1. **初回**は、パネルの「**全件を取得**」をタップする。
2. 一覧の読み込み → 声優・作者の取得の順に進みます。**進み具合と、残り時間**が出ます。
   - 目安は、**1 件あたり約 1 秒**です（100 件で約 2 分、1,000 件で約 15〜20 分、4,000 件超で約 1 時間弱）。
   - **終わるまで、Safari を前面に出したまま、画面を開いておいてください。** 画面が消えないようにする設定を使っていますが、ほかのアプリに切り替えたり、画面をロックしたりすると、止まります。充電しながらの利用をおすすめします。
   - 途中でやめたいときは、「中止」をタップします。
3. 完了と表示されたら、「**CSV を保存**」をタップする。ダウンロードの確認が出たら「**ダウンロード**」を選ぶ。
   - 保存先は、「ファイル」アプリの「ダウンロード」です。
4. Hikidashi を開き、「**設定 → CSV をインポート**」で、その CSV を選ぶ。

### 2 回目以降（新しく買った作品だけを足す）
1. パネルの「**前回の CSV を選ぶ**」をタップして、前回の CSV を選ぶ。Hikidashi から書き出した CSV でも、前回このスクリプトで作った CSV でも構いません。
2. 「**新着だけ**」をタップする。
   - 前回の CSV にある作品は取り直さず、**新しい作品だけ**を取得して、足します。
   - **お気に入り・メモ・非表示は、そのまま保たれます。**
   - 新しい作品は、**最後に買ったものが Hikidashi の一番上に来る順**で、CSV の末尾に追加されます。
3. 「CSV を保存」→ Hikidashi の「CSV をインポート」で取り込む。

前回の CSV を選ばなくても、この iPhone の Safari が、取得済みの作品を覚えているので、「新着だけ」は使えます。ただ、Safari の履歴・Web サイトデータを消すと、忘れます。**前回の CSV を選ぶ方が、確実**です。

### うまくいかないとき

| 症状 | 確認すること |
|---|---|
| **パネルが出ない** | ① 「設定 → アプリ → Safari → 機能拡張 → Userscripts」が**オン**か。② 「**他の Web サイト**」が「**許可**」か（または `dmm.co.jp` が「許可」か）。③ マイライブラリの**一覧のページ**を開いているか（詳細ページでは出ません）。④ プライベートブラウズ**ではない**か。⑤ アドレスバーの**ページメニュー**（「ぁあ」、iOS 27 では横線 2 本のアイコン）→「Userscripts」を開き、このスクリプトが**オン**か。⑥ ページを再読み込みする。⑦ Userscripts アプリを開いて、スクリプトが一覧に出ているか。 |
| ページメニューに「Userscripts」が出ない | 設定の「機能拡張」で、Userscripts が、オンになっていない可能性があります。ページメニュー →「機能拡張を管理」でも、オンにできます。 |
| 作品が 0 件 / 「見つかりませんでした」 | ログインしているか。マイライブラリの**一覧**を開いているか。DMM の画面の作りが変わった可能性があります（その場合は Issues へ）。 |
| 声優・作者が空 | DMM の詳細ページの作りが変わった可能性があります。最新のスクリプトか確認し、Issues へ。 |
| 途中で止まった | ほかのアプリに切り替えた、画面がロックされた、通信が切れた、などが原因です。もう一度、「全件を取得」（または、前回の CSV を選んで「新着だけ」）で、続きから取れます。 |
| 「CSV を保存」を押しても、保存されない | ダウンロードの確認が出ていれば、「ダウンロード」を選ぶ。「ファイル」アプリの「ダウンロード」を見る。それでも出ない場合は、「共有…」のボタンで、「ファイルに保存」を選ぶ。 |
| スクリプトを更新したい | Userscripts アプリの設定にある「更新を確認」を使うか、手順 3 を、もう一度行って、上書きする。 |

## 💻 PCで使う（Chrome拡張機能）

Chrome ウェブストアでは配布していません。次の手順で、手元の Chrome に読み込みます（Edge など Chromium 系でも同様です）。

1. [Releases](https://github.com/nemog9/dmm-doujin-exporter/releases/latest) から `dmm-doujin-exporter-vX.Y.Z.zip` をダウンロードして、解凍する（解凍したフォルダは、使い続ける間、削除しない）
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」から、解凍したフォルダを選ぶ
5. 更新するときは、新しい zip で同じフォルダを上書きし、`chrome://extensions` の拡張機能のカードで「再読み込み」を押す

ソースから使う場合は、このリポジトリをクローンして、同じ手順でフォルダを選べます。

### 使い方
1. DMM にログインし、[マイライブラリ](https://www.dmm.co.jp/dc/-/mylibrary/)を開く
2. 拡張機能のアイコンをクリック
3. （任意）前回エクスポートした CSV を読み込む → 差分のみ取得してマージ出力される
4. 「取得件数」を設定（0 で全件）
5. 「取得開始」をクリック

#### 最後までスクロール（既定）／高速モード
既定では、ライブラリを**最後までスクロール**して全件を確認し、CSV にない作品だけを取得します。
「最後までスクロール」のチェックを外すと高速モードになり、既存の作品に当たった時点で止まります（前回の続きだけを取りたいときに速い。ただし、途中に未取得の作品があると取りこぼす）。

#### ファイル名
前回の CSV を読み込んだ場合、そのファイル名のベース部分（例: `my-library`）に現在の日時を付けて保存されます。CSV なしで開始した場合は `doujin-library-YYYYMMDD-HHMMSS.csv` です。

#### 途中で止まるとき
完了メッセージに「ライブラリ N 件を確認。停止理由: …」が出ます。
- **既存の作品に到達した（重複検知）**: 既存 CSV を読み込んでいると、すでにある作品に当たった時点で止まる。ライブラリの途中に未取得の作品があるなら「最後までスクロール」を使う。
- **最後まで読み込んだ**: 新しい作品が最大 20 秒待っても増えなくなったら終了とみなす。確認件数がライブラリの実際の件数より少なければ、DMM 側の読み込みが止まっている可能性がある。
- **取得件数の上限に達した**: 「取得件数」に 0 以外を入れている。

## 出力される CSV

Hikidashi に、そのまま取り込める CSV です（UTF-8 BOM 付き）。

```
"title","url","creators","thumbnail_url","category","note","favorite","hidden"
```

| 列 | 内容 |
|----|------|
| title | 作品名 |
| url | 作品詳細ページの URL（`https://www.dmm.co.jp/dc/doujin/-/detail/=/cid=<作品ID>/`）。購入済みページ（マイライブラリ）の URL ではない |
| creators | サークル名・声優（ボイス）・作者（コミック・CG）を `\|` 区切りでまとめたもの |
| thumbnail_url | サムネイル画像 URL |
| category | ジャンル（ボイス / コミック / CG / 動画） |
| note | メモ（新規取得分は空。既存 CSV の値は保持） |
| favorite / hidden | `1` / `0`（新規取得分は空 = 取り込み先の既存値を保持） |

### 行の順番
- **既存の行（読み込んだ CSV の中身）は、順序もそのまま**です。
- **新しく取得した作品だけ**を、取得順（DMM は新しい購入が先頭）の**逆順**にして、末尾に足します。
- Hikidashi は、CSV の行の順に、新しい作品へ番号を振ります（一覧の「追加が新しい順」は、あとに入れたものが上）。そのため、**最後に買った作品が、Hikidashi の一番上に来ます。**
- 前回の CSV を使わずに、初めて書き出すときも、全件が、古い順（最後の行が最新）で出ます。

### 既存 CSV の読み込み（差分取得）
- 購入済みページの URL（`.../mylibrary/detail/=/product_id=…`）が入った CSV は、作品詳細 URL に変換して出力します。作品 ID は、どちらの URL からも取り出すので、差分取得は URL の種類に関係なく動きます。
- Hikidashi（CSVShelf）形式に加え、旧形式（`タイトル,サークル名,声優,ジャンル,URL,サムネイル,お気に入り,非表示`）も読めます。旧形式は、新形式に変換して出力します。
- Hikidashi から書き出した CSV を読み込めば、お気に入り・非表示・メモを保ったまま、差分だけ追加できます。

## プライバシー

- 取得した内容は、**ブラウザの中だけ**で処理して、CSV として手元に保存します。作者を含め、外部のサーバーには、何も送信しません。
- 通信するのは、ログイン済みのあなた自身の DMM のページ（`www.dmm.co.jp`）だけです。
- Chrome 拡張の権限（`activeTab`、`scripting`、`tabs`、`downloads`、`storage`）は、マイライブラリのページの読み取りと、CSV の保存、設定の保持にだけ使います。
- iPhone 版（Userscripts）は、`www.dmm.co.jp` のマイライブラリ（`/dc/-/mylibrary/…`）でだけ動きます。「新着だけ」のために、取得済みの作品 ID を、この端末の Safari の中（`localStorage`）に、覚えます。

## 注意事項

- DMM のマイライブラリページを開いた状態で使用してください。
- 作品数が多い場合、取得に時間がかかります（1 作品あたり約 1 秒）。
- DMM のページ構造が変わると、動かなくなる場合があります（不具合は [Issues](https://github.com/nemog9/dmm-doujin-exporter/issues) へ）。
- 短時間に大量のアクセスをしないよう、同時に取得する数と待ち時間を、控えめにしています。DMM の利用規約に従って、自己責任でお使いください。

## 開発

```
node --test test/csv.test.mjs
```

- CSV の読み書きと、詳細ページの解析は `csv.js`（popup と Service Worker で共有）。
- `userscript/dmm-export.user.js` は、iPhone 版です。処理の中身は、Chrome 拡張と同じで、1 ファイルで動かすために、必要な部分を写しています。
- `userscript/probe.user.js` は、画面の構造を調べるための診断用です（通常は使いません）。
