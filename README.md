# DMM Doujin Exporter

DMMマイライブラリの同人作品（ボイス・コミック・CG）をCSVShelf形式のCSVにエクスポートするChrome拡張機能。

エクスポートしたCSVは、iOSアプリ CSVShelf の「CSVをインポート」で取り込めます。

## 機能

- マイライブラリをスクロールして作品情報を自動収集
- 声優（ボイス作品）・作者（コミック・CG作品）を各作品の詳細ページから取得
- 既存CSVとのマージ出力（前回の続きから差分のみ取得）
- 重複検知モード（デフォルト）と全件探索モードの切り替え

## 出力形式

[CSVShelf](https://github.com/nemog9/csv-shelf)（iOS アプリ）にそのまま取り込める CSV。UTF-8 BOM 付き。

```
"title","url","creators","thumbnail_url","category","note","favorite","hidden"
```

| 列 | 内容 |
|----|------|
| title | 作品名 |
| url | マイライブラリの作品詳細 URL |
| creators | サークル名・声優（ボイス）・作者（コミック・CG）を `|` 区切りでまとめたもの |
| thumbnail_url | サムネイル画像 URL |
| category | ジャンル（ボイス / コミック / CG / 動画） |
| note | メモ（新規取得分は空。既存 CSV の値は保持） |
| favorite / hidden | `1` / `0`（新規取得分は空 = 取り込み先の既存値を保持） |

### 既存 CSV の読み込み（差分取得）
CSVShelf 形式に加え、旧形式（`タイトル,サークル名,声優,ジャンル,URL,サムネイル,お気に入り,非表示`）も読める。
旧形式を読み込んだ場合は、新形式に変換して出力する（サークルと声優は creators にまとめる）。
CSVShelf から書き出した CSV を読み込めば、お気に入り・非表示・メモを保ったまま差分だけ追加できる。

## インストール

1. このリポジトリをクローンまたはZIPでダウンロード
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」からフォルダを選択

## 使い方

1. DMMにログインし、[マイライブラリ](https://www.dmm.co.jp/dc/-/mylibrary/)を開く
2. 拡張機能アイコンをクリック
3. （任意）前回エクスポートしたCSVを読み込む → 差分のみ取得してマージ出力される
4. 「取得件数」を設定（0で全件）
5. 「取得開始」をクリック

### 全件探索モード

チェックを入れると、重複を検知しても最後までスクロールし続ける。  
通常は不要だが、ライブラリの途中に未取得の作品がある場合などに使用する。

### ファイル名

前回のCSVを読み込んだ場合、そのファイル名のベース部分（例: `my-library`）に現在の日時を付けて保存される。

```
my-library-20260501-153000.csv
```

CSVなしで開始した場合は `doujin-library-YYYYMMDD-HHMMSS.csv` で保存される。

## 動作の流れ

```
① スクロールフェーズ
   マイライブラリページを自動スクロールして作品一覧を収集
   （デフォルト: 既存IDと重複した時点で停止）

② 声優・作者取得フェーズ
   新規作品のみ詳細ページをfetchして声優/作者を取得

③ CSV出力
   既存CSVの内容 + 新規作品をマージしてダウンロード
```

## 開発

```
node --test test/csv.test.mjs
```

CSVの読み書きは `csv.js`（popup と Service Worker で共有）。

## 注意事項

- DMMのマイライブラリページを開いた状態で使用してください
- 作品数が多い場合、取得に時間がかかります（1作品あたり約0.5秒）
- DMMのページ構造変更により動作しなくなる場合があります
